# Entwicklung

Dieses Repository ist die private Arbeitsbasis für **Seanime Mobile**.

- Öffentliches Ursprungsrepository: `Lampe332/seanime-mobile`.
- Übernommene Basis: Branch `main`, vollständiger Quellcommit `f11e5c29c0cc58c14d2b22175dff723257fba063`.
- `origin` zeigt auf dieses private Repository; Zwischenstände werden hierher gepusht. Keine Releases oder Tags erstellen.
- Die Veröffentlichung im öffentlichen Repository erfolgt erst in einer späteren, ausdrücklich beauftragten Aufgabe.
- Die separate Play-Store-App **„Anime App“**, ihr Repository und ihre Installation sind ausgeschlossen.
- Vor einer späteren Installation auf dem Handy App-Identität, Signaturkompatibilität und Datenerhalt prüfen.

GitHub Actions sind in diesem privaten Repository deaktiviert.
